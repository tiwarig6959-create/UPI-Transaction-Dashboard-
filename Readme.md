# UPI Transaction Dashboard

An interactive Power BI dashboard that analyzes 2024 UPI transaction data to understand spending and balance trends across banks, cities and customer segments.

## Tools Used
- Power BI
- SQL (data cleaning)
- Python (data preparation)

## Dashboard Features
- Monthly transaction amount trends (line and column charts)
- Monthly remaining balance trends (line and column charts)
- 10 slicers for drill-down analysis: sender bank, receiver bank, city, device type, gender, age group, merchant, payment method, purpose, transaction type
- Page 2: matrix view of transaction amount and remaining balance by month, city and currency
- Bookmark navigation between views

## Data Preparation
The raw UPI transaction dataset was cleaned and prepared using SQL and Python before being loaded into Power BI.
